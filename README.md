
---

 🛠️ How to run it

1. Download the three files: `index_updated.html`, `style.css`, and `script.js`
2. Make sure they are in the same folder
3. Open `index_updated.html` in your browser
4. Fill out the form and see it respond in real-time!

---

 🧰 Tools Used

- HTML5 for structure
- CSS3 for styling (with transitions & effects)
- JavaScript for validation and interactivity



💡 Notes

- There’s no server or backend – everything runs in your browser
- Perfect for testing or learning how forms and validation work
- Feel free to customize it for your own needs



Thanks for checking it out! 🙌
